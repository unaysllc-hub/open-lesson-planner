# Open Lesson Planner

A browser-based lesson planning worksheet that helps educators structure objectives, activities, checks for understanding, differentiation, and assessment.

## Features

- Practical lesson fields with a clear teaching sequence
- Automatic local draft saving
- Print-friendly lesson plan output
- Export and import plans as JSON
- Responsive and keyboard-accessible interface
- No account or cloud storage

## Run locally

Open `index.html` in a modern browser.

## Data ownership

Drafts stay in the current browser. Export a JSON copy when plans need to be moved or backed up.
